## 1. 现有上报模式对比

### 1.1 已知的三种上报模式

| 模式 | WeighingMode | 上报接口 | 目标系统 | 中转 |
|------|-------------|---------|---------|------|
| **MaterialPlatform 模式** | Standard=0 | `IMaterialPlatformApi.SynchronizationOrderAsync`（POST `/api/Order/SynchronizationOrder`） | MaterialPlatform 服务端 | 无 |
| **Urban 模式** | UrbanMode=201 | `IUrbanManagementApi`（Refit） | UrbanManagement → 政府平台 | UrbanManagement |
| **Recycle 模式（新增）** | Recycle=301 | `IRecycleDataApi`（新 Refit） | **杭州市资源化利用厂** | **无（直连）** |

### 1.2 数据上报架构图

```
现有链路（SolidWaste, WM=1）：
MaterialClient → WeighingMatchingService → SynchronizationOrderAsync
    → POST /api/Order/SynchronizationOrder → MaterialPlatform 服务端

新链路（Recycle, WM=301）：
MaterialClient.Recycle → RecycleDataSyncService → IRecycleDataApi
    → POST /dataCenter/resourcePlace/productTransportRecord/v1/addBatch → 资源化利用厂
    → HMAC-SHA256 签名认证
```

### 2.3 调用链路

```
WeighingMatchingService.PushWaybillAsync()              // 公共入口（行 908）
  → PushNewWaybillsAsync()                               // 查找未同步运单（行 1287）
    → SyncNewWaybillAsync(waybill, ...)                  // 逐条同步（行 1192）
      → SynchronizationOrderInputDto.FromWaybill(waybill) // 转换 DTO

             dto.SolidWasteInfo = new SolidWasteInfoDto { ... }
```

### 2.4 错误处理

| 场景 | 处理方式 |
|------|---------|
| API 返回 `Success == false` | 标记 `SetPendingSync()`，下次重试 |
| 抛出异常 | 日志记录 `LogError`，不计数 |
| 批量处理 | 统计成功/失败数量 `LogInformation` |

### 3.3 HMAC-SHA256 签名认证（§2.2，已确认）

**请求头**：

| Header | 必填 | 说明 |
|--------|------|------|
| `X-AKZTJG-HMAC-SIGNATURE` | ✅ | API 输入参数签名结果（Base64 编码） |
| `X-AKZTJG-HMAC-ALGORITHM` | ✅ | 固定值：`hmac-sha256` |
| `X-AKZTJG-HMAC-ACCESS-KEY` | ✅ | 平台颁发的 accessKey |
| `X-AKZTJG-DATE-TIME` | ✅ | GMT+8 时区时间戳，格式：`Tue, 09 Nov 2021 08:49:20 GMT`（允许最大误差 100 秒） |

**签名字符串格式**：
```
{HTTP_METHOD}\n{sorted_query_string}\n{accessKey}\n{GMT_date}\n
```

### 4.2 HMAC 签名服务

```csharp
// MaterialClient.Recycle/Services/RecycleHmacSignService.cs
public class RecycleHmacSignService
{
    private readonly string _accessKey;
    private readonly string _secretKey;

    public (string Signature, string DateTime) BuildSignature(
        string httpMethod, string body)
    {
        var gmtDateTime = TimeZoneInfo.ConvertTimeBySystemTimeZoneId(
            DateTime.Now, "China Standard Time")
            .ToString("ddd, dd MMM yyyy HH:mm:ss 'GMT'", CultureInfo.InvariantCulture);

        // POST 请求无 query string，使用空字符串
        var sortedQuery = string.Empty;
        var stringToSign = $"{httpMethod}\n{sortedQuery}\n{_accessKey}\n{gmtDateTime}\n";

        using var hmac = new HMACSHA256(Encoding.UTF8.GetBytes(_secretKey));
        var hash = hmac.ComputeHash(Encoding.UTF8.GetBytes(stringToSign));
        var signature = Convert.ToBase64String(hash);

        return (signature, gmtDateTime);
    }
}
```

### 4.3 核心同步服务

```csharp
// MaterialClient.Recycle/Services/RecycleDataSyncService.cs
public class RecycleDataSyncService
{
    private readonly IWeighingRecordRepository _recordRepository;
    private readonly IRecycleDataApi _recycleApi;
    private readonly IAttachmentService _attachmentService;
    private readonly RecycleHmacSignService _hmacService;
    private readonly RecycleSyncOptions _options;
    private readonly ILogger<RecycleDataSyncService> _logger;

    private async Task SyncPendingRecordsAsync(CancellationToken ct)
    {
        var pendingRecords = await _recordRepository.GetPendingSyncRecordsAsync();

        foreach (var record in pendingRecords)
        {
            try
            {
                // 1. 读取关联附件（图片）→ Base64 编码
                var outPhotos = await LoadImagesAsBase64Async(record.Id, ct);

                // 2. 字段映射（WeighingRecord → RecycleTransportRecord）
                var transportRecord = MapToRecycleRequest(record, outPhotos);

                // 3. 构造 HMAC 签名
                var body = JsonSerializer.Serialize(new[] { transportRecord });
                var (signature, dateTime) = _hmacService.BuildSignature("POST", body);

                // 4. 调用资源化利用厂接口（JSON Array）
                var response = await _recycleApi.SubmitTransportRecordAsync(
                    new[] { transportRecord },
                    _options.AccessKey, signature, dateTime, ct);

                // 5. 更新同步状态
                if (response.Code == 200)
                {
                    record.SyncStatus = SyncStatus.Success;
                }
                else
                {
                    record.FailCount++;
                    record.FailMsg = response.Msg;
                    if (record.FailCount >= _options.MaxFailCount)
                        record.SyncStatus = SyncStatus.Abandoned;
                }
            }
            catch (HttpRequestException ex)
            {
                record.FailMsg = ex.Message;
                _logger.LogWarning(ex, "网络异常，下次重试");
            }
            catch (Exception ex)
            {
                record.FailCount++;
                record.FailMsg = ex.Message;
                _logger.LogError(ex, "同步失败");
            }

            await _recordRepository.UpdateAsync(record);
        }
    }

    private async Task<string> LoadImagesAsBase64Async(long recordId, CancellationToken ct)
    {
        var attachments = await _attachmentService.GetByRecordAsync(recordId);
        var base64List = new List<string>();

        foreach (var att in attachments)
        {
            var absPath = PathManager.ToAbsolutePath(att.LocalPath);
            if (!File.Exists(absPath))
            {
                _logger.LogWarning("图片文件缺失: {Path}", absPath);
                continue;
            }
            var bytes = await File.ReadAllBytesAsync(absPath, ct);
            // Base64 编码，不带标识头
            base64List.Add(Convert.ToBase64String(bytes));
        }
        // 多张图片用英文逗号分隔
        return string.Join(",", base64List);
    }

    private RecycleTransportRecord MapToRecycleRequest(
        WeighingRecord record, string outPhotos)
    {
        return new RecycleTransportRecord
        {
            DataNo = record.OrderNo ?? GenerateDataNo(record),
            PointNumber = _options.PointNumber,
            CarNo = record.TruckNo ?? string.Empty,
            ProductName = _options.ProductName,
            NetWeight = record.OrderGoodsWeight / 1000m,    // kg → 吨
            TareWeight = record.OrderTruckWeight / 1000m,   // kg → 吨
            GrossWeight = record.OrderTotalWeight / 1000m,  // kg → 吨
            OutTime = record.OutTime?.ToString("yyyy-MM-dd HH:mm:ss") ?? string.Empty,
            OutPhotos = outPhotos,
        };
    }
}
```

### 4.4 与 SolidWaste 同步服务的关键差异

| 维度 | SolidWaste（WM=1） | Recycle（WM=301） |
|------|-------------------|------------------|
| **HTTP 接口** | `SynchronizationOrderAsync`（Refit） | `IRecycleDataApi.SubmitTransportRecordAsync` |
| **目标地址** | 内部 MaterialPlatform URL | 外部资源化利用厂 URL |
| **请求 DTO** | `SynchronizationOrderInputDto`（单条 JSON Object） | `RecycleTransportRecord`（JSON Array，批量） |
| **认证方式** | 内部认证 | **HMAC-SHA256 签名**（accessKey + secretKey） |
| **响应判断** | `HttpResult<T>.Success` | `RecycleApiResponse.Code == 200` |
| **图片处理** | 附件先上传 OSS，再推送元数据 | **Base64 内嵌到请求体**（不带标识头，逗号分隔） |
| **重量单位** | kg（`OrderGoodsWeight`） | **吨**（÷1000 转换） |
| **中转层** | 无（直连 MaterialPlatform） | 无（直连资源化利用厂） |

## 7. 数据流完整路径（Recycle 新链路）

```
[地磅串口] → 重量数据 → [稳定性检测] → 重量稳定
                                         ↓
[海康威视 LRP] → 车牌识别 → 图片保存（AttachmentFile）
                                         ↓
                              [创建 WeighingRecord]
                              [关联 AttachmentFile]
                                         ↓
                         [RecycleDataSyncService 定时扫描]
                                         ↓
                         [查询未同步记录 + 关联附件]
                                         ↓
                    [读取附件 → Base64 编码（不带标识头，逗号分隔）]
                                         ↓
                    [字段映射 WeighingRecord → RecycleTransportRecord]
                    [重量 kg → 吨（÷1000）]
                    [时间 → yyyy-MM-dd HH:mm:ss]
                                         ↓
                    [构造 HMAC-SHA256 签名]
                    [4 个自定义 Header]
                                         ↓
                    [HTTP POST → /dataCenter/resourcePlace/.../addBatch]
                    [请求体: JSON Array]
                                         ↓
                    [解析响应: code==200 → 成功]
                    [更新 SyncStatus]
                                         ↓
                    成功 → SyncStatus = Success
                    失败 → FailCount++ → 重试
                    放弃 → SyncStatus = Abandoned（FailCount >= MaxFailCount）
```

## 8. 与现有同步链路的对比

### 8.1 GovClient → XiaoShanServe → 政府平台（旧链路）

```
GovClient → ServicePushWeightToGovApi → POST /Api/Post → XiaoShanServe → 转发 → 政府平台
```

特点：中转层（XiaoShanServe），5 秒轮询，`networkCompany` 选择目标。

```
MaterialClient.Urban → UrbanServerUploadService → POST /api/urban/weighing-records → UrbanManagement
```

特点：直连服务端，Refit 接口，UrbanManagement 再转发政府平台。

### 8.3 MaterialClient.SolidWaste → MaterialPlatform（固废链路）

```
MaterialClient → WeighingMatchingService → SynchronizationOrderAsync
    → POST /api/Order/SynchronizationOrder → MaterialPlatform
```

特点：WeighingMode=1 模式下通过共享同步服务上报，单条 JSON Object，内部认证。

### 8.4 MaterialClient.Recycle → 资源化利用厂（Recycle 链路，新增）

```
MaterialClient.Recycle → RecycleDataSyncService → HMAC签名
    → HTTP POST → /dataCenter/resourcePlace/productTransportRecord/v1/addBatch
```

特点：**直连外部第三方**，HMAC-SHA256 认证，JSON Array 批量提交，Base64 图片内嵌，重量单位为吨。
