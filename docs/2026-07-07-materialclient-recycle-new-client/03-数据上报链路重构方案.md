## 4. 同步服务设计

### 4.1 核心同步服务

```csharp
// MaterialClient.Recycle/Services/RecycleDataSyncService.cs
public class RecycleDataSyncService : IAsyncDisposable
{
    private readonly IWeighingRecordRepository _recordRepository;
    private readonly IRecycleDataApi _recycleApi;
    private readonly IAttachmentService _attachmentService;
    private readonly RecycleSyncOptions _options;
    private readonly ILogger<RecycleDataSyncService> _logger;
    private PeriodicTimer? _timer;
    private CancellationTokenSource? _cts;

    public async Task StartAsync()
    {
        _cts = new CancellationTokenSource();
        _timer = new PeriodicTimer(TimeSpan.FromSeconds(_options.PollIntervalSeconds));

        while (await _timer.WaitForNextTickAsync(_cts.Token))
        {
            await SyncPendingRecordsAsync(_cts.Token);
        }
    }

    private async Task SyncPendingRecordsAsync(CancellationToken ct)
    {
        // 1. 查询未同步记录（SyncStatus != 成功 && SyncStatus != 不再上传）
        var pendingRecords = await _recordRepository.GetPendingSyncRecordsAsync();

        foreach (var record in pendingRecords)
        {
            try
            {
                // 2. 读取关联附件（图片）
                var images = await LoadImagesAsync(record.Id, ct);

                // 3. 转换为资源化利用厂请求格式
                var request = MapToRecycleRequest(record, images);

                // 4. 调用资源化利用厂接口
                var response = await _recycleApi.SubmitWeighingDataAsync(request, ct);

                // 5. 更新同步状态
                if (response.Success)
                {
                    record.SyncStatus = SyncStatus.Success;
                }
                else
                {
                    record.SyncStatus = SyncStatus.Failed;
                    record.FailCount++;
                    record.FailMsg = response.Message;

                    if (record.FailCount >= _options.MaxFailCount)
                    {
                        record.SyncStatus = SyncStatus.Abandoned;
                    }
                }
            }
            catch (HttpRequestException ex)
            {
                // 网络异常不计数
                record.FailMsg = ex.Message;
                _logger.LogWarning(ex, "网络异常，下次重试");
            }
            catch (Exception ex)
            {
                record.FailCount++;
                record.FailMsg = ex.Message;
                _logger.LogError(ex, "同步失败");
            }

            await _recordRepository.UpdateAsync(record);
        }
    }

    private async Task<string[]> LoadImagesAsync(long recordId, CancellationToken ct)
    {
        // 通过 AttachmentFile 关联查询
        var attachments = await _attachmentService.GetByRecordAsync(recordId);
        var images = new List<string>();

        foreach (var att in attachments)
        {
            var absPath = PathManager.ToAbsolutePath(att.LocalPath);
            if (!File.Exists(absPath))
            {
                _logger.LogWarning("图片文件缺失: {Path}", absPath);
                continue;
            }
            var bytes = await File.ReadAllBytesAsync(absPath, ct);
            images.Add(Convert.ToBase64String(bytes));
        }
        return images.ToArray();
    }

    private RecycleWeightRequest MapToRecycleRequest(WeighingRecord record, string[] images)
    {
        // 字段映射待接口文档 §2.2 确认后细化
        return new RecycleWeightRequest
        {
            CarNo = record.CarNo,
            CarNoColor = record.CarNoColor,
            GrossWeight = record.GrossWeight,
            WeighingTime = record.SnapTime,
            Images = images,
            // ... 资源化利用厂特有字段待填充
        };
    }
}
```

### 4.2 与 SolidWaste 同步服务的关键差异

| 维度 | SolidWaste 同步服务 | Recycle 同步服务 |
|------|-------------------|-----------------|
| **HTTP 接口** | `SynchronizationOrderAsync` | `IRecycleDataApi.SubmitWeighingDataAsync` |
| **目标地址** | 内部服务端 URL（配置） | 资源化利用厂外部 URL（配置） |
| **请求 DTO** | SolidWaste 内部 DTO | `RecycleWeightRequest`（按 §2.2 定义） |
| **认证方式** | 内部认证（可能 LicenseInfo / BuildLicenseNo） | **待确认**（接口文档 §2.2 可能定义认证方式） |
| **响应判断** | 内部约定（如 `code == 200`） | 按 §2.2 文档约定 |
| **中转层** | 可能经过 UrbanManagement | **无中转**（直连） |

## 6. 数据流完整路径（Recycle 新链路）

```
[地磅串口] → 重量数据 → [稳定性检测] → 重量稳定
                                         ↓
[海康威视 LRP] → 车牌识别 → 图片保存（AttachmentFile）
                                         ↓
                              [创建 WeighingRecord]
                              [关联 AttachmentFile]
                                         ↓
                         [RecycleDataSyncService 定时扫描]
                                         ↓
                         [查询未同步记录 + 关联附件]
                                         ↓
                         [MapToRecycleRequest]
                         (WeighingRecord → RecycleWeightRequest)
                         (AttachmentFile → Base64 images)
                                         ↓
                         [HTTP POST → 资源化利用厂 §2.2]
                                         ↓
                         [解析响应 → 更新 SyncStatus]
                                         ↓
                         成功 → SyncStatus = Success
                         失败 → FailCount++ → 重试
                         放弃 → SyncStatus = Abandoned（FailCount >= MaxFailCount）
```

## 7. 与现有同步链路的对比

### 7.1 GovClient → XiaoShanServe → 政府平台（旧链路）

```
GovClient → ServicePushWeightToGovApi → POST /Api/Post → XiaoShanServe → 转发 → 政府平台
```

特点：中转层（XiaoShanServe），5 秒轮询，`networkCompany` 选择目标。

### 7.2 MaterialClient.Urban → UrbanManagement（城管链路）

```
MaterialClient.Urban → UrbanServerUploadService → POST /api/urban/weighing-records → UrbanManagement
```

特点：直连服务端，Refit 接口，UrbanManagement 再转发政府平台。

### 7.3 MaterialClient.Recycle → 资源化利用厂（Recycle 链路，新增）

```
MaterialClient.Recycle → RecycleDataSyncService → HTTP POST → 资源化利用厂 §2.2
```

特点：**直连外部第三方**，无中转，接口规范由外部文档定义。
