# §2.3 收料（物料进场车次）字段对照

> 接口：`POST /dataCenter/resourcePlace/materialTransportRecord/v1/addBatch`  
> 文档：[§2.3](../../../MaterialMonospec/docs/SyncDoc/杭州市资源化利用厂数据接入接口V1.0.md#23-物料进场车次数据批量新增接口)  
> 适用：`DeliveryType.Receiving`，且 **运单已完成**

设计定稿见 [00-调研总览.md](./00-调研总览.md)。

---

## 必填字段

| 接口字段 | 类型 | UI / 数据来源 | 同步映射（设计） | 状态 |
|----------|------|--------------|-----------------|------|
| `dataNo` | String | 无 UI；权威 **`Waybill.OrderNo`** | 直接映射 | ✅ 已定 |
| `pointNumber` | String | `RecycleSync:PointNumber` | 配置 | ✅ |
| `carNo` | String | 车牌 | `Waybill.PlateNumber` | ✅ |
| `materialName` | String | 材料 → **`Material.Name`** | 同 productName 来源 | ✅ |
| `netWeight` | **kg** | UI 净重（**吨显示**） | 按 §2.3 文档 **kg** 换算后写入 | ✅ 已定 |
| `inTime` | String | 父视图进场时间 → `Waybill.JoinTime` | `yyyy-MM-dd HH:mm:ss` | ✅ |
| `inPhoto` | Base64 | 附件 | **进场侧图片**（见下） | ✅ 已定 |

### `inPhoto` 取图规则（设计定稿）

- 与 §2.2 一致：**API 使用进场侧图片**。
- 取图：`EntryPhoto` → `UnmatchedEntryPhoto` → `Lpr`（[04](./04-仅有Lpr设备方案.md)）。
- UI 上 PhotoGrid 的进/出场格仍表示称重**进/出场次**；市平台 `inPhoto` / §2.2 的 `outPhotos` **均不强制使用 ExitPhoto**。

---

## 可选字段

| 接口字段 | 映射（设计） |
|----------|-------------|
| `carrierCompanyName` | **`ProviderId` → `Provider.ProviderName`**（已定） |
| `tareWeight` / `grossWeight` | UI 吨 → §2.3 **kg** |
| `unitPrice` / `payAmount` | 暂无 UI |

---

## 收料称重语义（UI）

- 进场满车 → 毛重；出场空车 → 皮重；净重 = 进场 − 出场。
- UI **吨**；API §2.3 **kg**——Mapper 负责换算，与地磅原始单位无关。
