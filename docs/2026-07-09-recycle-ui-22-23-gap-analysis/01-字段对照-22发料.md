> 接口：`POST /dataCenter/resourcePlace/productTransportRecord/v1/addBatch`  
> 文档：[§2.2](../../../MaterialMonospec/docs/SyncDoc/杭州市资源化利用厂数据接入接口V1.0.md#22-成品销售车次数据批量新增接口)  
> 适用业务：`DeliveryType.Sending`（发料）

## 必填字段

| 接口字段 | 类型 | UI / 数据来源 | 持久化 | 同步层（当前） | 状态 |
|----------|------|--------------|--------|---------------|------|
| `dataNo` | String | SolidWaste 表单「联单编号」→ `SolidWasteOrderNumber`；**Recycle 无此 UI** | `WeighingRecord` / `Waybill` ExtraProperties | `Waybill.OrderNo` 或 `R-{recordId}` | ⚠️ Recycle 见 [05-Recycle独立表单页面.md](./05-Recycle独立表单页面.md) |
| `pointNumber` | String | 无（配置） | — | `RecycleSync:PointNumber` | ✅ 配置项 |

| `productName` | String | 表单「材料名称」 | `Material.Name`（经 MaterialId） | `ResolveProductNameAsync` → `Material.Name` | ✅ |
| `netWeight` | BigDecimal（**吨**） | 父视图「净重」 | `Waybill.OrderGoodsWeight`（**kg**） | kg ÷ 1000 | ✅ 单位转换正确 |
| `outTime` | String | 父视图「出场时间」 | `Waybill.OutTime` | `yyyy-MM-dd HH:mm:ss` | ✅ 发料场景 |
| `outPhotos` | String（Base64） | 无表单；硬件抓拍 | `WeighingRecordAttachment` + `AttachmentFile` | `ExitPhoto` / `Lpr` / `UrbanPhoto` | ⚠️ 依赖设备；文档字段名为出场照 |

## 页面有、接口无（SolidWaste 扩展字段）

| 页面字段 | 存储 | 说明 |
|----------|------|------|
| 所属镇街 | `SolidWasteInfo.Street` | SolidWaste 导出/业务用，§2.2 不需要 |

完成订单时 SolidWaste 强制镇街 + 联单编号；**Recycle 独立表单不包含这两项**（见 [05-Recycle独立表单页面.md](./05-Recycle独立表单页面.md)）。

## 重量与时间语义（发料）

发料称重流程（`Waybill.SetWeight`，`DeliveryType.Sending`）：

- 进场（空车）→ 皮重 `OrderTruckWeight`
- 出场（满车）→ 毛重 `OrderTotalWeight`
- 净重 `OrderGoodsWeight` = 出场 − 进场

父视图展示单位标为「吨」，库内 `Order*Weight` 与地磅一致（实现按 **kg** 处理，上报 ÷1000）。需现场确认地磅读数单位与显示标签一致。

## §2.2 专项结论

**UI 层**：核心发料字段（车牌、成品名、重量、出场时间）可采集。  
**同步层**：已实现最小 §2.2 管线，但缺 `carrierCompanyName`、`dataNo` 与联单对齐、可选商务字段；且**未过滤**仅发料记录（收料也会进入本端点）。
