# §2.2 发料（成品销售车次）字段对照

> 接口：`POST /dataCenter/resourcePlace/productTransportRecord/v1/addBatch`  
> 文档：[§2.2](../../../MaterialMonospec/docs/SyncDoc/杭州市资源化利用厂数据接入接口V1.0.md#22-成品销售车次数据批量新增接口)  
> 适用：`DeliveryType.Sending`，且 **运单已完成**

设计定稿见 [00-调研总览.md](./00-调研总览.md)。

---

## 必填字段

| 接口字段 | 类型 | UI / 数据来源 | 同步映射（设计） | 状态 |
|----------|------|--------------|-----------------|------|
| `dataNo` | String | 无 UI；权威 **`Waybill.OrderNo`** | 直接映射 | ✅ 已定 |
| `pointNumber` | String | 配置 `RecycleSync:PointNumber` | 配置 | ✅ |
| `carNo` | String | 表单车牌 → `Waybill.PlateNumber` | 优先 Waybill | ✅ |
| `productName` | String | 材料 → **`Material.Name`** | `ResolveProductNameAsync` | ✅ |
| `netWeight` | **吨** | UI 净重（吨）→ `Waybill.OrderGoodsWeight` | 按 §2.2 文档单位写入 | ✅ |
| `outTime` | String | 父视图出场时间 → `Waybill.OutTime` | `yyyy-MM-dd HH:mm:ss` | ✅ |
| `outPhotos` | Base64 | 无表单；附件 | **进场侧图片**（见下） | ✅ 已定 |

### `outPhotos` 取图规则（设计定稿）

- 与 UI PhotoGrid「进/出场」语境分离：**API 统一使用进场侧图片**。
- 取图顺序（运单已完成后）：`EntryPhoto` → `UnmatchedEntryPhoto` → 记录级 `Lpr`（无 CameraConfigs 双附件方案见 [04](./04-仅有Lpr设备方案.md)）。
- 不依赖 `ExitPhoto` 作为 §2.2 上报来源。

---

## 可选字段

| 接口字段 | 映射（设计） |
|----------|-------------|
| `carrierCompanyName` | **`ProviderId` → `Provider.ProviderName`**（已定） |
| `tareWeight` / `grossWeight` | UI 吨 → 按 §2.2 文档单位 |
| `unitPrice` / `payAmount` / `saleContractNo` 等 | 暂无 UI，可不报 |

---

## Recycle 表单不含的 SolidWaste 字段

镇街、类型、联单编号：Recycle 不展示（[05](./05-Recycle独立表单页面.md)），不上报市平台。

---

## 发料称重语义（UI）

- 进场空车 → 皮重；出场满车 → 毛重；净重 = 出场 − 进场。
- UI 重量 **一律按吨显示**；写入 API 时 **仅按 §2.2 接口要求的单位（吨）** 换算，与地磅原始刻度无关。
