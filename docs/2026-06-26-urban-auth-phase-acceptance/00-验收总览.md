## 1. 阶段目标回顾

本阶段旨在完成 **5001 城管客户端 JWT 授权闭环** 的设计落地与三仓代码对齐：

| 目标 | 说明 |
|------|------|
| **语义分离** | `AccessCode`（接入码）与 `MachineCode`（设备码）分列，废弃 `FdBuildLicenseNo` |
| **JWT 签发归属** | 由 BasePlatform 统一签发，`iss=BasePlatform` |
| **在线激活** | 授权码 → Urban 代理 → BasePlatform `activate-urban` → 客户端 `LatestJwtToken` |
| **离线授权** | BasePlatform `license-file` / `.urban` 导入（实现保留，UI 暂隐藏） |
| **启动验权** | 客户端本地 `StaticLicenseChecker` 验签，不实施 `verify` API |

## 3. 架构闭环（当前态）

```
MaterialClient.Urban
  │  POST /api/urban/auth/activate  { productCode:5001, code, machineCode }
  ▼
UrbanManagement (UrbanAuthController → UrbanAuthActivateAppService)
  │  POST /api/auth/activate-urban
  ▼
BasePlatform.PublicApi (AuthController)
  │  验 Redis 一次性码 → 回写 MachineCode → 签发 JWT
  ▼
响应 jwtToken → 客户端 LicenseInfo.LatestJwtToken
  │  启动：StaticLicenseChecker (iss=BasePlatform)
  ▼
进入主界面
```
