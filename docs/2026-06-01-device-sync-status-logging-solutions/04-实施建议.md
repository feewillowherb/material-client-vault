# 实施建议

> **通信约束**：Monitor 使用 **SignalR**（传输层 WebSocket，Hub 路径默认 `/hubs/device-monitor`）；客户端 `Microsoft.AspNetCore.SignalR.Client`，服务端 `Volo.Abp.AspNetCore.SignalR`。不实现 HTTP 轮询/长轮询上报或 SignalR 传输降级。详见 [05-SignalR技术选型与集成.md](./05-SignalR技术选型与集成.md)。称重仍走 Refit HTTP。

> **Monitor 可选**：`DeviceMonitoring:Enabled` 为 **appsettings 总开关**。MaterialClient **默认 false**，MaterialClient.Urban **默认 true**；关闭或故障时核心称重链路必须可用。详见 [00-调研总览](./00-调研总览.md)、[02-状态监控方案](./02-状态监控方案.md) §Monitor 隔离。

## Monitor 模块注册与故障隔离（实施必做）

### 原则

1. Monitor 服务（SignalR `HubConnection`、心跳、摄像头探测、远程错误日志）在 **独立 `IHostedService`** 中运行，异常在内部捕获。
2. **`UrbanServerUploadService` 不得引用** `IDeviceMonitorHubConnection` / `IHeartbeatService`。
3. `DeviceMonitoring:Enabled == false` 时不 `HubConnection.StartAsync`，不注册 SignalR 相关 `HostedService`（可注册 no-op `IDeviceMonitoringState`）。
4. 全局异常处理中调用 `IErrorLogCaptureService` 前检查 `EnableRemoteLogging`；失败时降级为仅写本地日志。

### 条件注册示例

```csharp
// src/MaterialClient.Urban/DependencyInjection/MonitoringServiceCollectionExtensions.cs
public static IServiceCollection AddUrbanDeviceMonitoring(
    this IServiceCollection services,
    IConfiguration configuration)
{
    var section = configuration.GetSection("DeviceMonitoring");
    services.Configure<DeviceMonitoringOptions>(section);

    if (!section.GetValue<bool>("Enabled"))
    {
        services.TryAddSingleton<IDeviceMonitoringState, DisabledDeviceMonitoringState>();
        return services;
    }

    services.AddSingleton<IDeviceMonitorHubConnection, DeviceMonitorHubConnectionService>();
    services.AddSingleton<IDeviceStatusMonitor, ClientStatusMonitor>();
    services.AddSingleton<IErrorLogCaptureService, ErrorLogCaptureService>();

    if (section.GetValue("EnableHeartbeat", true))
        services.AddHostedService<HeartbeatHostedService>();

    if (section.GetValue("EnableCameraMonitoring", true))
        services.AddHostedService<CameraMonitoringHostedService>();

    services.AddHostedService<DeviceMonitorSignalRHostedService>();
    return services;
}
```

MaterialClient 非 Urban 宿主在 `Program` / 模块中调用同一扩展方法即可；仅 **appsettings 默认值** 不同。

**客户端错误捕获:**
```csharp
// src/MaterialClient.Urban/Services/ErrorLogCaptureService.cs
public class ErrorLogCaptureService : IErrorLogCaptureService
{
    private readonly ConcurrentQueue<ErrorLogEntry> _logQueue;
    private readonly IErrorLogTransmitter _transmitter;
    private readonly ILogger<ErrorLogCaptureService> _logger;
    
    public ErrorLogCaptureService(IErrorLogTransmitter transmitter)
    {
        _transmitter = transmitter;
        _logQueue = new ConcurrentQueue<ErrorLogEntry>();
        
        // 启动后台传输任务
        Task.Run(async () => await ProcessLogQueueAsync());
    }
    
    public void CaptureError(Exception exception, ErrorContext context)
    {
        var logEntry = new ErrorLogEntry
        {
            Id = Guid.NewGuid(),
            Timestamp = DateTime.UtcNow,
            Level = LogLevel.Error,
            Message = exception.Message,
            StackTrace = exception.StackTrace,
            Source = context.Source,
            ClientId = context.ClientId,
            MachineName = Environment.MachineName,
            AppVersion = context.AppVersion,
            AdditionalData = JsonSerializer.Serialize(context.AdditionalData)
        };
        
        _logQueue.Enqueue(logEntry);
        
        _logger.LogError(exception, "Error captured: {Message}", exception.Message);
    }
    
    private async Task ProcessLogQueueAsync()
    {
        while (!_cts.IsCancellationRequested)
        {
            try
            {
                if (_logQueue.TryDequeue(out var logEntry))
                {
                    await _transmitter.TransmitAsync(logEntry);
                }
                else
                {
                    await Task.Delay(TimeSpan.FromMilliseconds(100), _cts.Token);
                }
            }
            catch (Exception ex)
            {
                _logger.LogError(ex, "Failed to process log queue");
                await Task.Delay(TimeSpan.FromSeconds(5), _cts.Token);
            }
        }
    }
}
```

### 网络故障处理（仅 Monitor 通道）

```csharp
// src/MaterialClient.Urban/Services/NetworkResilienceService.cs
// 仅当 DeviceMonitoring.Enabled 时注册；不得被 UrbanServerUploadService 调用
public class NetworkResilienceService
{
    private readonly IDeviceStatusReporter _reporter;
    private readonly IDatabaseService _databaseService;
    
    public async Task ReportWithResilienceAsync(DeviceStatusDto status)
    {
        try
        {
            await _reporter.ReportDeviceStatusAsync(status);
        }
        catch (Exception ex)
        {
            // 监控通道故障：本地排队，不影响称重 HTTP
            await _databaseService.StorePendingStatusAsync(status);
            _logger.LogWarning(ex, "Monitor channel unavailable, status queued locally");
        }
    }
    
    public async Task RetryPendingTransmissionsAsync()
    {
        var pendingStatuses = await _databaseService.GetPendingStatusesAsync();
        
        foreach (var status in pendingStatuses)
        {
            try
            {
                await _reporter.ReportDeviceStatusAsync(status);
                await _databaseService.MarkAsTransmittedAsync(status.Id);
            }
            catch
            {
                // 继续尝试下一个
                continue;
            }
        }
    }
}
```

### 数据一致性保证

```csharp
// src/UrbanManagement.Core/Services/DeviceStatusConsistencyService.cs
public class DeviceStatusConsistencyService
{
    public async Task EnsureConsistencyAsync()
    {
        // 修复长时间未更新的客户端状态
        var staleClients = await _deviceStatusRepository.GetListAsync(
            c => c.IsOnline && 
                 c.LastHeartbeat < DateTime.UtcNow.AddMinutes(-15));
        
        foreach (var client in staleClients)
        {
            client.IsOnline = false;
            client.LastOffline = DateTime.UtcNow;
            await _deviceStatusRepository.UpdateAsync(client);
            
            _logger.LogInformation("Marked client {ClientId} as offline due to stale heartbeat", 
                client.ClientId);
        }
    }
```
