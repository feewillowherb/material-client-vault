# Urban BasePlatform 授权方案快速参考

## 推荐架构：UrbanManagement 代理

**采用 UrbanManagement 代理方案**：
- MaterialClient.Urban → UrbanManagement → BasePlatform.PublicApi
- GovProject 统一管理 MachineCode
- 简化客户端部署

> **注**：UrbanManagement 通过 BasePlatform.PublicApi 通信，BasePlatform.WebApi 用于 UI 相关操作。

## 核心概念

### 授权类型

| 类型 | 值 | 描述 | 使用场景 |
|-----|---|------|---------|
| 离线授权 | 0 | 通过导入授权文件激活 | 网络隔离环境 |
| 在线授权 | 1 | 通过输入授权码激活 | 有网络环境 |

### 关键组件

| 组件 | 职责 |
|-----|------|
| BasePlatform | 授权管理、机器码存储、在线验证 |
| MachineCodeProvider | 获取稳定的机器码 |
| OfflineAuthValidator | 启动时离线验证 |
| OnlineAuthActivator | 授权码在线激活 |
| OnlineAuthVerifier | 定期在线验证 |

## 快速流程图

### 离线授权流程

```
现场人员 → 脚本获取机器码 → BasePlatform 录入 → 下载授权文件
                                              ↓
客户端 ← 导入授权文件 ← 解密验证 ← 写入 SQLite
    ↓
启动验证：机器码比对 → 过期检查 → 签名验证
```

### 在线授权流程（代理模式）

```
管理员 → BasePlatform.WebApi 生成授权码 → 提供给用户
                                           ↓
客户端 → 输入授权码 → 获取机器码 → 调用 UrbanManagement API
                                        ↓
UrbanManagement → 转发到 BasePlatform.PublicApi → 验证授权码
    ↓                                         ↓
更新 GovProject ← 返回授权信息 ← 持久化机器码
    ↓
返回给客户端 → 写入 SQLite → 激活成功
```

### 在线验证流程（代理模式 - 双方比对）

```
客户端启动 → 获取当前机器码
                   ↓
    ┌──────────────┼──────────────┐
    ↓              ↓              ↓
SQLite 机器码 == 当前机器码 == UrbanManagement 机器码
    ↓                              ↓
本地验证                      API 本地验证
    └──────────────┼──────────────┘
                   ↓
            全部一致 → 授权有效
            任一不一致 → 授权失效，关闭程序
```

## 关键数据结构

### 授权文件（离线）

```json
{
  "version": "1.0",
  "productCode": "UrbanManagement",
  "machineCode": "MACHINE-CODE",
  "proId": "project-guid",
  "authBeginDate": "2026-06-23T00:00:00",
  "authEndDate": "2026-12-31T23:59:59",
  "authType": 0,
  "authToken": "GUID-TOKEN",
  "signature": "digital-signature"
}
```

### SQLite 授权记录（客户端极简存储）

| 字段 | 类型 | 说明 |
|-----|------|------|
| ProId | string | 项目ID |

> **说明**：客户端只需存储 ProId。验证时通过 ProId + 当前机器码向 UrbanManagement 进行实时验证。UrbanManagement 在 GovProject 中管理 MachineCode、AuthToken 等授权信息。

### BasePlatform Material_MachineCode

| 字段 | 说明 |
|-----|------|
| MachineCode | 客户端机器码 |
| AuthType | 授权类型 |
| AuthStatus | 授权状态 |
| AuthToken | 授权令牌 |
| AuthEndDate | 授权结束时间 |

## API 速查

### UrbanManagement 代理 API（客户端调用）

#### 在线激活代理

```
POST /api/urban/auth/activate-proxy
参数: code(授权码), machineCode, proId
返回: authToken, authEndDate, proId, proName
```

#### 本地验证

```
POST /api/urban/auth/verify-local
参数: proId, machineCode
返回: isValid, proId, proName, authEndDate
```

#### 授权文件获取代理

```
GET /api/urban/auth/license-file?machineCode=xxx
返回: 加密的授权文件
```

### BasePlatform.PublicApi API（UrbanManagement 调用）

> **说明**：UrbanManagement 通过 BasePlatform.PublicApi 调用以下接口。BasePlatform.WebApi 用于 UI 相关操作。

#### 获取授权文件

```
GET /api/auth/license-file
参数: productCode, machineCode, proId, authEndDate
返回: 加密的授权文件
```

#### 在线激活

```
POST /api/auth/activate
参数: productCode, code(授权码), machineCode
返回: authToken, authEndDate, proId, proName
```

#### 在线验证

```
POST /api/auth/verify
参数: productCode, authToken, machineCode
返回: isValid, authStatus, machineCodeMatch
```

## 验证规则总结

### 启动时验证（代理模式）

1. ✅ 从 SQLite 读取 ProId
2. ✅ 获取当前机器码
3. ✅ 调用 UrbanManagement API（ProId + 当前机器码）
4. ✅ UrbanManagement 验证：当前机器码 == GovProject.MachineCode
5. ✅ 检查授权状态和过期时间

### 在线验证（定期/手动，代理模式）

1. ✅ 从 SQLite 读取 ProId
2. ✅ 获取当前机器码
3. ✅ 调用 UrbanManagement API（ProId + 当前机器码）
4. ✅ UrbanManagement 验证授权有效性
5. ✅ **机器码比对**（当前机器码 == GovProject.MachineCode）

### 失败处理

任一验证失败 → 提示"授权无效，请联系管理员" → **关闭程序**

## 常见问题

### Q: 机器码不稳定怎么办？
A: 使用多重硬件特征（CPU、主板、MAC、硬盘），提供机器码重新绑定流程

### Q: SQLite 被篡改怎么办？
A: 客户端仅存储 ProId（项目ID），不存储敏感授权信息。即使 SQLite 被篡改，UrbanManagement 服务器端验证仍会检测到异常。

### Q: 网络中断无法在线验证？
A: 提供离线宽限期（如 7 天），超过宽限期后失效

### Q: 授权文件泄露怎么办？
A: 授权文件绑定机器码，其他机器无法使用；定期在线验证
